Nota: Se considera que una UA está expuesta cuando se encuentra dentro de zonas con susceptibilidad media, alta o muy alta de las capas consideradas en este análisis. Las UA clasificadas como “no expuestas” se encuentran fuera de estas categorías y no implica ausencia absoluta de amenaza o riesgo.

El análisis de exposición considera las Unidades de Atención que cuentan con georreferenciación validada a nivel de parroquia, las cuales corresponden al 88 % del total. Este porcentaje puede variar según el reporte mensual del SIIMTDH.
